# 🌿 EcoLife - Environmental Awareness Website

**EcoLife** is a clean, modern, and responsive front-end website designed to promote environmental awareness, sustainable living, and waste reduction. It offers educational content on global environmental challenges, actionable eco-tips, an interactive quiz, and a newsletter registration form with client-side JavaScript validation.

---

## ✨ Features

- **Responsive Navigation Bar:** Includes a collapsible hamburger menu for small screen sizes and smooth scrolling section links.
- **Dark Mode Toggle:** Supports switching between light and dark visual themes with updated color palettes.
- **Hero & Highlights:** Section for key environmental principles (Protect Forests, Save Water, Reduce Waste, Save Energy).
- **Educational Sections:** 
  - Details on pressing environmental issues (Air Pollution, Deforestation, Climate Change).
  - Breakdown of the 3 Rs of Waste Management (*Reduce*, *Reuse*, *Recycle*).
  - Everyday eco-friendly tips.
- **Interactive Eco Quiz:** Immediate feedback on user choices using standard vanilla JavaScript form handling.
- **Registration Form:** Validated form requiring input checks (name character validation and consent check).
- **Dynamic Copyright Year:** Footer copyright year updates automatically via JavaScript.

---

## 🛠️ Built With

- **HTML5:** Semantic structural elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom CSS variables for theme management, CSS Grid, Flexbox, and responsive `@media` queries.
- **JavaScript (ES6+):** Dynamic theme toggling, event handling, DOM manipulation, and input pattern validation (`strict mode`).
